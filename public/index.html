支援 CLIProxyAPI 憑證、~/.codex/auth.json、codex-tools 的 accounts.json，可多選檔案或直接貼上。

    設定

    • 右上角按鈕開啟 hi.yml，到 GitHub 按 Run workflow；手動執行做什麼由旁邊的開關決定，排程固定查額度＋送 hi。
    • 只有送 hi 會通知 Discord；只查額度不發任何通知。
    • Webhook 建立方式：Discord 頻道 → 編輯頻道 → 整合 → Webhook → 新 Webhook → 複製網址。
